# Calculadora Boleado

App de custos da A2B Confeitaria a partir da planilha de compras.

- Montagem de potes 140 ml e 250 ml
- Sabores com gramaturas da planilha (granulado, morango, Oreo, Bis, paçoca, leite em pó)
- 20% de luz e gás
- Preço sugerido com margem ajustável
- Edição dos preços de compra

Abra `index.html` ou sirva a pasta com qualquer servidor estático.
